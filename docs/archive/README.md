# Archivo documental

Este directorio conserva material de producto, diseño y ejecución que ya no gobierna el estado actual. Los documentos se archivan, no se eliminan, para preservar decisiones y trazabilidad.

No uses sus precios, planes, rutas, comandos ni planes de trabajo como instrucciones vigentes sin contrastarlos con el código y la documentación actual.
