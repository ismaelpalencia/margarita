## Criterios de estado

- **vigente:** referencia mantenida para el uso actual.
- **histórico:** conserva contexto; no gobierna el estado o precio actual.
- **archivar:** decisión pendiente de mover a `archive/` tras revisar enlaces y uso.
- **eliminar:** solo si no hay referencias, no es legal/operativo y el reemplazo está documentado. No hay documentos eliminados en esta pasada.
- **legal:** aviso, contrato o material de privacidad; no modificar sin responsable legal.
- **comercial:** mensajes, precios o propuestas; confirmar la fuente de precios antes de enviar.
- **operativo:** procedimiento para alta, despliegue, pruebas, soporte o continuidad.

La carpeta [`archive/`](archive/README.md) conserva documentos desplazados. En esta pasada se movieron documentos históricos, no se borró su contenido. `docs/bitacora-batches.md` no existía; la bitácora localizada en la raíz fue archivada.
